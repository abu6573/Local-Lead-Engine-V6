# Project Guidelines & Rules

## Terminology & Naming Conventions
- **Contractor Terminology**: Always use "Contractor" / "Contractors" (or "Contractor Categories") instead of "Trade" / "Trades".
- **Category Naming**: Always use "Home Remodeling Contractors" instead of "Remodeling Contractors".
- **Lead / Project Values**: Avoid mentioning hardcoded dollar ranges for project tickets or lead values (e.g. avoid "$25,000 to $150,000", "$35,000 to $90,000+", "$25k+, $50k+", "$30,000 to $100,000+"). Instead, use qualitative phrases such as high-margin replacements, full-scope installations, whole-home renovations, and design-build projects.
